## First release candidate (2026-10-24; signed preview unchanged)

- Start with both sidebars closed. Drag a main/root node to move its whole branch rather than pan; drag blank canvas to marquee-select. Hold middle mouse to pan, press H to use the hand tool, and press V or Escape to return to selection. The main window uses native `.resizable` AppKit style; **physical mouse edge/corner dragging is not yet independently verified** (the safe global-event probe stopped when desktop focus switched to other apps).
- Right-click blank canvas → Arrange Map (整理布局) runs the existing layout on the entire tree, including folded descendants; one Undo restores stored positions. Edit → Find… (⌘F) searches all titles, can navigate folded matches and refreshes after document changes.
- File → Insert Image… or paste PNG/JPEG/HEIC/HEIF/TIFF into a selected node to add a picture child. Pictures appear above optional double-click-editable titles; drag a *single selected* picture's lower-right handle to scale it proportionally. Unsupported, oversized, damaged, or collectively unsavable images are rejected before adding a node. `.mindmap.json` keeps the image; a `.mindnode` source/package remains read-only.
- File → Export PDF/PNG/JPG/Markdown… exports the **entire map**, not the current viewport. Destinations must not exist or live inside a `.mindnode` package. Markdown preserves title hierarchy but **does not embed pictures** and says so in the output. Neither this release nor these exports writes `.mindnode`.
- `bash Tests/run-first-release-visible.sh` launches an isolated, signed, visible/key/frontmost native synthetic App and checks six sidebar toggles, programmatic resizing, root branch drag, marquee, image, Find, Arrange/Undo and whole-map PNG. Other focused `swiftc -D HEADLESS_TEST Sources/*.swift Tests/<Name>.swift -framework AppKit` checks are **offscreen only**.
