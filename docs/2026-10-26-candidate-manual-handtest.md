# OpenMindFlow 新候选：人工手测（不触碰旧版）

此清单只用于新建、独立标识的候选 App。不要关闭、激活或替换仍在使用的 `build/MindMap-Feedback-20261026.app`，不要修改来源 `.mindnode` 或首版预览压缩包。

1. 先确认候选窗口**未最大化/未进入全屏**，且窗口当前大小明显大于 640×400 点。把指针移到候选窗口右下角最外侧边框，按住并向右下拖动，再向左上拖回。观察外框**实际宽度、高度**是否随手势改变，最小尺寸是否停在 640×400 点。再分别试右边缘与下边缘。记录“实际通过 / 无法拖动 / 命中位置不清楚”，不要把程序调用 `setFrame`、静态 `.resizable` 标记或禁用脚本的 `SKIP 77` 当成通过。
2. 拖动前在候选文档中为一个长标题根节点、一个左分支节点添加注释；拖动后确认节点世界位置、纸张图标与注释内容不丢失，边栏开合不累计偏移。
3. 在候选文档中新建一级分支，分别用右键菜单和直接拖过根节点中心将其切到左侧；给该分支增加子节点，确认连接线、下划线、加号和便签图标都面向正确侧。再切回右侧，分别撤销和重做，每次只回退一步。保存为新的 `.mindmap.json`，关闭**候选文档**后重新打开，检查方向、标题和注释仍在。
4. 打开主题面板：只见 Tropical、Teal（亮）及 Slate、Coffee（暗）四张大预览卡，根居中、每侧三条颜色不同的枝线；选择任一主题后核对文档背景及根、枝真实颜色，切换浅色/深色系统外观仍保持主题本身明暗。旧 Rainbow/Candyland 文档可打开，但不出现对应可选卡。
5. 将左右分支同在的候选文档另存到**全新** PNG、PDF、JPG，核对左、右节点和便签图标没有裁切；切勿把含左分支的数据尝试回写来源 `.mindnode`。如旧格式不支持左方向，应收到明确不支持提示且不得产生半成品目标。

导入文件若含手工固定在特殊坐标的同级节点，向左分支添加新节点后请额外留意与原节点是否重叠；新节点会继承左侧，但本轮不承诺任意原生固定坐标的全面避碰。遇到时记录位置与截图，勿修改原 `.mindnode`。

若步骤 1 不通过，请保留候选窗口未最大化时的屏幕尺寸、窗口大致尺寸、尝试拖动的位置与屏幕边缘距离，以便针对命中区或约束复现；无需关闭或改变旧手测 App。
