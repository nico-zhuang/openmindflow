# 原版静态快捷键 → 独立 MindMap 覆盖审计

本审计只比较[原版 MainMenu.nib 静态清单](2026-10-20-mindnode-menu-inventory.md)的 **104 个带键菜单条目**和独立原型的显式代码；不是 104 个互不重复的组合键，也不是运行时行为复刻率。原版可用条件、快捷键冲突分流、输入焦点均未做受控运行时对照。安装包仍是旧版；以下“已接入”指提交 `a3183d4` 的源码和无窗口测试，不指旧安装版。

| 静态条目数 | 证据界定 |
| ---: | --- |
| 13 | 具有同键、同名或同类操作的显式原型入口，但原版运行时语义未经验证 |
| 1 | ⌘O Open 的原型入口仅打开 `.mindmap.json`，并不等价于原版原格式打开 |
| 3 | 有类似操作但**不**有相同显式按键：Edit Title ⌘Return（原型用输入/双击）、Close ⌘W（原型用关闭按钮）、Detach Node 静态大写 `D`+Command（原型显式 ⌘⇧D，大小写的 AppKit 路由未对照） |
| 87 | 无显式同键动作，可能有系统文本控件原生能力；不得直接推论“原版运行时有而原型完全没有” |

13 项同键入口的对象 ID：`38` Tab 新子节点；`93` ⇧Return 新主节点；`126` ⌥Tab 新父节点；`148` ⌘S 保存；`155` Return 新同级；`241` ⌘Q 退出；`293` Delete 删除节点；`310` ⌘Z 撤销；`343` ⇧⌘Z 重做；`634` ⌥Return 前插同级；`1029` ⌥. 折叠；`1250` ⌘↑ 同级上移；`1343` ⌘↓ 同级下移。另有对象 `183` ⌘O，只按键相同、文件能力不等价。源代码入口：[App.swift](../../Sources/App.swift)、[MapModel.swift](../../Sources/MapModel.swift)；回归：[CanvasCommandTests.swift](../../Tests/CanvasCommandTests.swift)、[MapModelTests.swift](../../Tests/MapModelTests.swift)。

**不得盲目扩展的冲突**：Tab 的 New Child（38）与 Indent（931）分属 Node/Organize；⌘1 的 Mind Map（1205）与 Styles（1222）并存。大写键不能不经验证折叠成小写：Paste as Text（811，`V`）/Paste（1009，`v`）、Detach（850，`D`）/Duplicate（1305，`d`）虽有相同 Command 掩码，键值不同；是否隐含 Shift 仍需原版临时图/文本框受控对照。Find（324，`f`）/Focus Mode（1161，`F`）同样是大小写不同的 Command 组合；菜单项目存在不代表同一模式可用。

**后续优先验证而非假定的簇**：
- 结构/大纲/选择：⌘←→ 同级移动（693、1078）、Tab Indent、⇧Backtab Outdent、Outline 模式、多选。
- 内容：节点复制粘贴与 Duplicate、链接、注释、任务、边界；确认剪贴板格式前不要往原包回写。
- 视图：折叠全部/逐层、概览/选区缩放、焦点和布局；现有原型仅画布平移/缩放及固定树布局。
- 文件：原版文档版本与导出、资源/样式；原型保持 `.mindnode` v9 **只读部分字段**导入和自有 JSON 保存。

每项进入“已还原”前至少有三层证据：原版静态条目、无私人资料的原版受控运行时观察、原型的同场景测试/GUI 核验。当前只覆盖第一层和部分原型无窗口测试；不得从 14/104 计算产品功能完成比例。
