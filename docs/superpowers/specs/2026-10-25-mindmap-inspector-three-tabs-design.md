# MindMap 三页原生样式栏设计（2026-10-25）

## 依据与边界

- 用户给出原版三张截图：画笔页分为形状、图像位置、边缘、分支、字体、思维导图和画布；文档页展示所选节点注释且节点右键可“编辑注释”；调色板页为 Classic 下的 Tropical、Rainbow、Candyland 等可滚动主题卡。
- 用户确认**不要标签页**：顶部只显示画笔、文档、调色板三个页签，不能留下标签图标或无效占位页。
- 保留已批准的主节点独立形状、子节点文字落在线条上（无常驻边框）、导入原版 `.mindnode` 只读、原有字体/对齐/线色/线宽的混合选择与 Undo 行为。主题卡不得暗示实际不存在的子节点彩色框。
- 这是现有第二版开发分支的一次迭代，不新增第三份签名用户版；现有用户文件和首版签名预览不被覆盖。

## UI 与真实功能

1. **画笔页**沿用现有 `StyleInspector` 的安装字体预览、字号、对齐、线色预设＋系统更多、分档线宽、实线/虚线。选中根节点时这些分支控件实际作用于其出线，子节点自身显式样式优先，不能只写入根节点不可见的连接属性。按截图改为原生分组与可滚动内容，在 260–320 pt 右侧栏仍可操作。增补与现有数据/绘制匹配的根节点形状（矩形、圆角）及填充色；固定宽度复用现有节点宽度模型。仅在所选对象适用时启用编辑；不增加无作用的四向图片布局、边缘阴影或布局避碰开关。画布背景色提供“跟随系统/浅色/深色”及系统取色板“更多…”，作为**文稿级**设置保存，并让屏幕与 PDF/PNG/JPG 导出一致；默认仍跟随系统。
2. **文档页**用原生可滚动文本编辑器显示所选单节点的纯文本注释；无选中或多选时不可编辑，切换页签或选中节点、保存、导出（尤其是实验性 MindNode 复制）、应用级撤销/重做、打开新文稿或关闭窗口前先提交一次 Undo，并在未保存提示出现前更新 dirty 状态；原节点编辑目标不能因新节点选中而丢失或错写，从不丢失尚在输入框中的最新字符；现有标题输入框若因 32 MiB 上限拒绝改名，也必须保留未提交文本并阻止切节点/保存/关闭，不能先移除编辑器。节点右键“编辑注释”自动选择节点、展开右栏并聚焦文档页。注释限制 UTF-8 最多 64 KiB，读入不可信 JSON 校验；空注释不制造无效 Undo。注释显示不改原节点标题/主题字体；需要时用小徽记表明存在注释，不把完整注释混进 PNG/JPG/PDF 画面。Markdown 只导出标题层级时明确提示未包含注释，不能无声遗漏。
3. **调色板页**以 AppKit 绘制三张紧凑导图预览卡（Tropical、Rainbow、Candyland），卡片展示实际可得到的根节点填充与各级分支配色，不能直接复制原软件资源或以截图代替真实效果。点选是文稿级主题选择，优先级为节点显式颜色 > 用户选定文稿主题 > 只读导入的原版颜色/主题 > 现有默认外观；切换即时重绘且可一键 Undo/Redo，保存/重开后可选状态、颜色、整图导出一致。原版导入的主题与逐节点字体/颜色不得因**打开**或切换标签页被覆盖；显式点选预设才替换文稿主题的继承色。

## 数据流及兼容

- `MapNode` 增加可选注释和实际支持的根节点外观字段；`MapModel` 的变更走现有快照/验证/Undo。`OwnMapDocument` 增加可选文稿级主题（及已实现才加入的画布色）；纯旧文稿仍可读取。关系和文稿级设置均为空时仍以旧根数组编码；有文稿级设置时写 version=1 的文稿对象而不静默丢失。旧 `readOwnJSON`/`writeOwnJSON` 包装器不得覆写它们不认识的文稿级设置。
- 现有 `.mindnode` 实验导出仍只能支持明确的简单树；遇到注释或新外观不受支持时**拒绝并解释**，绝不静默丢字段。私人原件不参与修改或测试。
- 保持默认跟随系统的画布与窗口外观；主题的背景若未通过文稿级持久化，不擅自固定成截图中的浅色。

## 验证与完成定义

- 先为三页切换/无标签图标、注释右键进入及重开/撤销、主题预览与实际颜色、混合选择/原版导入样式保留、非有限颜色与超长注释拒绝写 RED 回归，再实现最小改动。
- 运行相关测试及 33 组不夺取桌面的离屏回归，安全构建**现有开发 App**仅在用户旧进程退出后进行；另以独立合成原生窗口验证可见/可交互 GUI，旧 `.mindnode`、首版签名包及用户下载内容维持原样。
- 本轮只可宣称三页中的已测试功能；原版 MindNode 兼容写入、尚未实现的截图控件、第二版签名预览不因样式栏完成而自动算通过。
