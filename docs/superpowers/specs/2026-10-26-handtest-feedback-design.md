## 决策与取舍

- 只画便签图标、主题卡片静态图片、子节点自由移动到左边，是投入少但功能与保存/连接线脱节的伪修复，不采纳。
- 推荐四项真实集成：根据非空 `MapNode.note` 绘图；复现真实窗口边缘拖拽后修命中/窗口约束；宽幅程序绘制主题卡片并让每个主题 ID 控制真实画布/根节点/线条的颜色；给主节点一级分支持久化左右侧，让整个子树布局和线条镜像，保留现有右侧为默认。比纯截图方案复杂，但能测试、撤销、保存。
- 不做所有节点无约束的自由画布排布或全面复刻 MindNode 功能；它会扩大碰撞、导出、键盘导航和导入兼容的范围，不属于这轮反馈。

## 行为约定

1. **便签标记**：节点 `note` 非空且不是纯空白时，画布在子节点文字及底线末端外侧、根节点内容右端内侧保留可见小便签符号（深浅外观保持对比）。删空注释立即消失；缩放、导出、Undo/Redo、另存和重开保持一致。不显示注释内容；不把图标误作为另一种笔记数据。无障碍名称应说明有注释。可点击图标打开已有注释页仅在不引入错误选择/误触时实现，非本轮阻塞条件。
2. **窗口**：保持当前原生 `NSWindow` 的可调整尺寸语义和 640×400 下限。现有 `.resizable` 与 `setFrame` 测试不足以证明边缘手势。原拟采用隔离合成原生窗口的全局指针拖拽，但 2026-10-26 独立安全审查发现可能留下全局按键并误投用户窗口，故禁用且未运行；**仅由用户对新候选手动验证真实边缘拖拽**。只修复经其实际复现的命中区域、约束或工具栏/分栏干扰；未验证之前不得称已修复。缩放时不改变节点世界坐标、丢注释、让边栏开关累积漂移；不强制把用户运行窗口激活或关闭。
3. **主题栏与主题**（2026-10-26 用户最新修正，覆盖先前十一款方案）：在 260–320pt 侧栏仅显示四张卡片：亮色 Tropical、Teal；暗色 Slate、Coffee。每张卡片按可用宽度呈近原版宽幅比例，预览占主要面积，名称缩小并使用次级文字色；统一滚动、选择态和 VoiceOver 名称。四款均为真实样式，预览通过程序绘制布局与根、线、背景，不嵌入用户截图或冒用源素材；所见颜色映射到应用后的根填充、分支线、文字对比及文档背景。单节点显式颜色优先于主题默认。亮暗分类以实际画布颜色为准：Tropical 和 Teal 在 macOS 深色外观下仍须呈浅色画布，Slate 和 Coffee 呈暗色；此前 Tropical 跟随系统外观的背景须改为浅色主题默认，但节点显式背景色仍优先。**兼容边界**：旧 Rainbow、Candyland ID 与颜色及原有系统背景行为依旧可读、可导出，不在四款选择列表显示；本轮未公开的 Vintage、Greyscale、Blackberry、Blackboard、Swing 不需要新增到最终文件格式。四款选择/撤销/另存/重开与导出一致，原版像素级一致性在截图之外不宣称。
4. **左侧子树**：仍默认在右侧创建根分支；将任一主节点的一级分支拖至根节点左侧或用右键明确选择左侧时，将该分支及其子孙镜像排在左侧。持续编辑/添加子节点继承所在侧，不产生穿过根节点的右侧连接；子节点下划线与父子弯线朝向匹配。将分支移回右侧可逆、一次操作一个 Undo；序列化可选方向字段（旧 JSON 缺失默认为右侧），保留导入 `.mindnode` 的真实坐标和只读源，不自动改写它们。拖放、折叠、调整宽度、选中、复制粘贴、布局适配及 PNG/PDF/JPG 需验证两侧同存场景。

## 验收边界

- 便签、四主题和左侧子树各有先失败的聚焦回归及通过结果；窗口只保留静态/程序化诊断收据，物理手势在用户对新候选实际手测之前不得报PASS。仅显式执行安全无窗口测试组，不运行可能抢焦点的 `WindowResizeTests`/`AppAccessibilityTests` 作为 headless。
- 任何其它已通过安全审查的可见 GUI 测试均须隔离测试 App、Finder 前台、输入空闲≥180秒；全局鼠标注入窗口边缘旅程已禁用并移除源码，绝不执行。真实物理边缘拖拽标注未验证并交给用户手测，不能以 `setFrame` 冒充。
- 审查源码及 33 组既有安全回归；追加聚焦新测试。构建全新、唯一标识的开发候选，不签发第二个正式预览、不覆盖现有手测 App 或首版 ZIP；新 App 仅在安全时/用户明确要求时打开。
