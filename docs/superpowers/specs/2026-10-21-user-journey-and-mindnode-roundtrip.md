# MindMap 用户任务与 MindNode 安全往返方案

## 目标与当前事实

用户要求按「打开现有 `.mindnode` → 修改 → 保存新 `.mindnode` → 仍能在原版打开」来判断可用性，而不是按菜单数量计进度。当前 `File → Open…` 只接收 `.mindmap.json`；另有 `File → Open MindNode (Read-only)…`，仅导入 v9 **目录包**、二进制 plist 的文字/UUID/树/折叠，存入内存模型，`Save` 只能写自有 JSON。四份匿名授权 v9 包在 CLI 只读解析通过；历史一次合成包 GUI 导入曾成功，当前真实用户路径、中文 IME 和拖放手感未验收。原版安装及任何授权用户包始终只读，不检查授权实现或复制私有素材。

## 路线选择

- **拒绝「只凭当前 MapModel 重建整个包」**：模型没有备注、样式、资源、链接、未知字段，生成同扩展名会静默丢失信息。
- **采用「新副本 + 原包模板的窄字段补丁」**：从合成/明确授权的 v9 包读取原始 plist 结构及资源清单，节点按 UUID 对应；未改字段保留原值，未经证明的编辑类型拒绝导出，而不是猜字段。始终另存到事前不存在的 `.mindnode` 目标；原包路径及文件字节不参与写入。
- **不把格式开放当作已知事实**：本机已安装 `rea` v6.7.0 CLI，可读 Mach-O 元数据、导出的 Swift 符号和界面资源（主程序 Evidence `ev_3a79c4de30ad1ab2974f1cf9bb77b9ff7ddbfdc956c89cc4f17466bee12f471b`）；`MindNodeKitObjC` 的静态选择器出现资源保存相关名称（Evidence `ev_332efbb68969fbe267f46f5d0a63173136301e3e0b437127ea8f314132df19ac`），不构成格式说明。Ghidra/Hopper/IDA/Kuna 均未配妥，**目前不能反编译深层原生函数**；即使以后有伪代码，也不是原源码，更不能照符号名猜写出器。原版实测须仅用临时空白/合成资料且确保不会恢复私人窗口。

## 分阶段门槛（先过关再扩大范围）

| 阶段 | 用户可完成的任务 | 自动检查（必须全部通过） | 有界人工/GUI 门槛 |
| --- | --- | --- | --- |
| 0：基线 | 从一个明确的 `Open…` 入口选自有 JSON 或可识别 v9 `.mindnode`，错误有明确提示 | 合成 JSON/v9/损坏/不支持版本分别选择；失败不替换当前编辑树、不碰源文件；当前全部模型/布局/导入/画布测试通过 | 独立 App 最多一次受控启动、合成包与现有自有 JSON 各试一次；若无权限则记录未验，不声称通过 |
| 1：复制原格式 | 用合成 v9 包「另存原格式新副本」，内容未编辑 | 只允许新目标；排除软链接、包外引用、不规则文件与过大包，记录源清单哈希；复制后原有资源与 `contents.xml` 逐文件哈希相同；已存在目标/中途失败均不覆盖、不遗留半成品；重读成功 | 如果可安全避免私人窗口，原版仅打开合成新副本一次；否则明确等待，不假称兼容 |
| 2：窄字段编辑 | 导入→仅改支持的纯文本标题/折叠→另存新 v9 包→重读 | 原始未知 plist 键及未改标题富文本语义保留，资源字节与名称不变，UUID 唯一/引用不悬空；多图/空图、中文/emoji/转义、装饰标题分别测试；源包哈希不变；不支持的富文本修改**拒绝原格式导出**但可存自有 JSON | 用一次合成输出在原版打开并核对修改前后，观察异常立即停止；绝不拿授权原件试写 |
| 3：结构编辑 | 再开放新建/移动/删除和多图，形成日常可用闭环 | 对每个被改 UUID 做增删改/父子关系与未知节点字段、附件/链接/任务引用不变量验证；不能安全重连的动作关闭原格式保存入口；撤销/重做与保存重读树一致 | 原版对同一**临时**图的增删改、拖放、缩放作有界对照；独立 App 同场景 GUI 复测 |
| 4：体验扩展 | 解决真正阻断任务的编辑、导航与信息展示，再逐类补多选/剪贴板/大纲/样式 | 每批保留最小失败回归、构建、旧格式兼容矩阵；用户任务需能从打开走到保存及重新打开 | 中文 IME、长/多行标题、拖动反馈、30 节点导航等在独立版实测；功能组逐项与原版临时图对照 |

**每次停线**：任一字段、资源、节点引用或原包字节可能丢失/改变时，停止 `.mindnode` 写出并保留 JSON 出口；不把「当前代码可解析」写成「MindNode 可打开/再保存」。不会修改已安装的旧 MindMap 或 `/Applications/MindNode.app`，新构建另存且一次只测一个实例。原版其他版本、单文件载体和未知复杂内容在得到独立样本及往返证据前仍只读或拒绝。

## 当前下一步

先消除 `Open…` 只显示 JSON 的用户误导，用一条入口清楚地区分自有 JSON 与 v9 只读导入，同时保留已有警告和保存目标隔离。然后做复制原格式新副本的安全检查；通过阶段 1 后才允许对原格式动一个字段。任何 GUI 结果与未验收项分列，不能靠无窗口模拟冒充手感验证。
