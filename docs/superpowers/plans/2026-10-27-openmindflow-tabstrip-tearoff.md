# OpenMindFlow Tab Strip and Tear-Off Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put browser-like horizontal/vertical document tabs beneath the toolbar, add per-window `＋`/`⌘T`, and reorder, detach and merge the same document session safely.

**Architecture:** A custom `DocumentTabStrip` owns only tab presentation and a private in-process dragging token. `WindowSession` owns ordered `DocumentSession` references and orientation; a separate transaction coordinator moves existing session objects between live windows. A drag cancellation or ambiguous release never mutates document membership.

**Tech Stack:** Swift 6.2.1, AppKit `NSView`, `NSDraggingSource`/`NSDraggingDestination`, Foundation `UUID`, UserDefaults; arm64 macOS 26. Tests compile with `swiftc -suppress-warnings -D HEADLESS_TEST Sources/*.swift Tests/NAME.swift -framework AppKit -framework AVKit -framework AVFoundation -o "$bin"`.

## Global Constraints

- Depends on every task in `docs/superpowers/plans/2026-10-27-openmindflow-document-sessions-windows.md` being GREEN and committed. 0.4.0 prior source is already on GitHub feature branch at `6522e8d`; do not push incomplete 0.5, modify running 0.4 bundles, or write any original `.mindnode`.

- No model serialization/cloning, reload, Save/Export, undo modification, dirty reset or implicit source write during tab switching, reordering, tear-off or merge. At most one window owns a `DocumentSession` at any instant.

On an ambiguous AppKit drag end, fail closed without tear-off; do not claim feature complete until verified physical release-vs-Escape behavior and actual cross-window drop.

### Task 2: Transactional same-instance reorder and cross-window merge

**Files:** Create `Sources/DocumentTabTransfer.swift`, `Tests/DocumentTabTransferTests.swift`; modify `Sources/WindowSession.swift`, `Sources/DocumentTabStrip.swift`.

**Interfaces:** `struct DocumentDragToken { let id: UUID; let documentID: UUID; let sourceWindowID: UUID; let sourceIndex: Int }`; `final class DocumentTabTransfer` owns a process-local `[UUID: (document: DocumentSession, source: WindowSession, generation: UInt64)]` map and `func begin(document: DocumentSession, source: WindowSession) -> UUID`, `func move(token: UUID, to target: WindowSession, insertion: Int) -> Bool`, `func cancel(token: UUID)`. It uses identity (`===`) and live membership checks, never serializes source paths or map data. Only a successful move updates source and target arrays/selected IDs and reparents the existing workbench; canceled/replayed/stale/foreign tokens do nothing. Source's last-tab window closes **after** successful move, with no dirty prompt because the session lives in the target.

- [ ] **Step 1: Write RED transfer tests.** Three documents A/B/C in source and D in target: move B after C, assert order A/C/B and exactly one owner; move A into target before D, assert A `===` old session and same canvas/model/undo/dirty/archive/URL/digest; source active selection chooses a surviving neighbor, target active A; last source transfer closes empty source only after success. Cover no-op drop, index past end, stale/replayed token, target closed before drop, token referring to no longer owned doc, and injected reparent refusal: all must preserve source and target membership and document bytes. Test `insertionIndex` against x midpoint in horizontal and y midpoint in vertical, with post-removal index decrement.
- [ ] **Step 2: Run RED.** Compile/run `DocumentTabTransferTests` independently; expect missing transaction type, not unsafe real-window drag.
- [ ] **Step 3: Implement pure coordinator.** Revalidate token/generation, source membership and target liveness **before mutation**. Same-source reorder removes then adjusts insertion index (`if destination > original { destination -= 1 }`); cross-window transfer snapshots both arrays/selections and old view parent, performs one reparent and array update, and restores snapshots/parent on thrown failure. `WindowSession.remove` on successful last-tab move closes the empty source without invoking document close confirmation. Consume token once on success; `cancel` invalidates without side effects. Put pixel/layout drag visuals outside this transactional class.
- [ ] **Step 4: Run GREEN.** Run `DocumentTabTransferTests`, `DocumentTabStripTests`, `DocumentSessionIsolationTests`, `MultiWindowLifecycleTests`, `VideoCanvasTests`, then production link and independent read-only review of exactly-once ownership and rollback.

### Task 3: Native drag frontend with positively confirmed tear-off release

**Files:** Modify `Sources/DocumentTabStrip.swift`, `Sources/DocumentTabTransfer.swift`, `Sources/WindowSession.swift`; create `Tests/TabDragSignalTests.swift`; extend `Tests/DocumentTabTransferTests.swift`.

**Interfaces:** Private `NSPasteboard.PasteboardType("local.openmindflow.document-tab")` contains only token UUID bytes; `DocumentTabStrip` is `NSDraggingSource` and accepts the token as destination within this process only. A source-side `DragReleaseSignal` records a **positively observed mouse-up** for the same drag and separately records Escape/cancel. `finish(token: UUID, locationOnScreen: CGPoint, operation: NSDragOperation, signal: DragReleaseSignal)` tears off only when the token is live, `operation == []`, release is positively observed, not canceled, and point lies outside *every* eligible tab strip; otherwise it cancels with original session intact. Do not infer release from `.none` or ending location alone: AppKit also reports `.none` for Escape.
