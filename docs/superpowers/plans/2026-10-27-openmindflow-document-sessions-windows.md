# OpenMindFlow Document Sessions and Windows Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract independent per-document state and add safe multiwindow lifecycle so `⌘N` opens a new window without losing or overwriting another document.

**Architecture:** `DocumentSession` owns exactly one live canvas/model/workbench plus its native file identity and MindNode provenance. `WindowSession` owns a window and an ordered set of documents with explicit active selection; AppDelegate keeps global menus/settings and routes to a validated window rather than a singleton canvas. This plan ends with functional multiple windows and independent documents; the companion tab-strip plan adds visible horizontal/vertical tabs and tear-off/merge.

**Tech Stack:** Swift 6.2.1, AppKit, AVKit, Foundation binary plist, CryptoKit, Darwin; arm64 macOS 26. Compile each never-ordered synthetic test as `swiftc -suppress-warnings -D HEADLESS_TEST Sources/*.swift Tests/NAME.swift -framework AppKit -framework AVKit -framework AVFoundation -o "$bin"`.
