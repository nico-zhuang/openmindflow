# OpenMindFlow 0.3.0 本机人工手测（未执行）

这是一份**等待本人在醒来后执行**的检查清单，不是已经通过的 GUI 结果。此次开发不会自动打开、聚焦或关闭已有候选窗口；旧候选可能有未保存内容，不要用新包覆盖旧应用，也不要在旧窗口里代替测试。`.mindnode` 原文件始终只读，另存使用 `.mindmap.json`。

## 启动与窗口

1. 从新的独立文件名解压本轮 OpenMindFlow 0.3.0 候选到新位置；不要替换旧候选。若来自本地 DMG，这是 **ad-hoc 本机签名、未公证**的测试包，并非 Apple Developer ID 正式发布，Gatekeeper 可能阻止首次启动。不要因为测试说明而对未知来源的程序绕过系统安全确认。在能安全启动时核对 Finder 与 Dock 中实际显示的是用户 v2.1 图标，而非只看 `.icns` 字节或 Info.plist 声明。
2. 在未最大化时，分别从左、右、上、下四条边和角落拖动窗口；确认分栏/画布随之伸缩，不会始终被固定为 1280×700。再用系统窗口最大化/全屏分别检查中央画布与外围背景是否同色，侧边栏与工具栏没有异常黑色边框。此条必须用实际鼠标和真实窗口验证，离屏视图大小测试不能代替。
3. 载入一份**自己允许用于手测的只读副本**，观察根节点往左的第一条主干/根端转弯是否平滑；确认左侧树与主题/Note 图标和已有 JSON 保存仍正常。

## 检查器与工具栏

4. 在右侧依次切换 **Style／Notes／Themes** 纯文字标签；测试中英语言后标签完整、没有 SF Symbol 图标。Style 顶部 FONT 区应靠近滚动区顶端，短窗口仍能滚到底；离屏宽度 260/320pt 测到此前约 75pt 的可见首节空隙缩至约 12pt，但外层标题栏仍需本机目测。
5. 默认工具栏应只有新主节点、新子节点、新兄弟节点、折叠、适配画布、纲要、样式七项常用操作（以及系统弹性空间），不应再有默认 Undo/Redo 占位。Undo/Redo 仍在 Edit 菜单并可通过自定义工具栏添加；核对缩窄窗口可用性。

## 空白、媒体与内部拖动

6. 左键单击画布空白后，选择高亮消失且标题/便签没有被改动。接着粘贴一段文本，应该在点击处创建独立主节点，原节点保持不变；一次 Undo 只移除新根。同样试空白处**右键→Paste**，不得编辑上次选中的标题；在空白清选后按方向键不应凭旧节点 ID 重选。
7. 选中一个明确节点时，粘贴有效 PNG/JPEG/HEIC 或 MOV/MP4/M4V 仍应创建它的子节点；空白清选后粘贴相同内容应在空白点击处建立独立根。再从 Finder 拖一张有效图片与一个小于 16 MiB 的短视频到画布空白、到一个现有节点，分别检查根/子节点、像素/播放、单步 Undo 与保存/重开。媒体应该嵌入独立 JSON，不要用需保密或体积过大的素材；坏扩展名、损坏数据和超出图片 8 MiB／视频 16 MiB／整个文档 32 MiB 的文件应拒绝，不改变内容。
8. 拖一个子节点靠近受弹簧动画影响的目标，停在**眼睛看到的目标**附近释放，核对最终父节点与拖动期间高亮预览一致。也试在大幅远离目标后松开不误入、Escape 取消恢复、同级间隔、左侧分支拖动和 65% 覆盖规则；实际手感只能由本人判断。
